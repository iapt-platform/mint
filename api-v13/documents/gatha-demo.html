偈颂（Gatha）排版 Demo

为阅读页增加 hangnum / gatha1 / gatha2 / gatha3 / gathalast 五个 class 的排版支持。 核心诉求：偈颂之间的间隔 > 偈颂内部行之间的间隔，且偈颂与散文混排时有明显区分。

本 Demo 的排版规则：
  • hangnum（偈颂号）悬挂在左侧页边，右对齐，字号缩小，与首行基线对齐。
  • gatha1/2/3/last（偈颂行）整体缩进 2.5rem，行间只留 0.3em 的小间距。
  • gathalast（末行）下方留 1.75em 的大间距，把相邻两首偈颂隔开。
  • 偈颂折行时悬挂缩进 1.25em，续行比首行更靠右，不会误看成新的一行。
  • 散文（prose）顶格、行距正常；偈颂缩进 + 收紧行距，混排时一眼可分。
  • centered（居中文本）水平居中，用于开头致敬语与经末「……竟」。

A · 巴利原文偈颂（带偈颂号 hangnum）

数据取自《宝经》（Ratanasutta，book 154）原文。每首前有 hangnum，行数 2～4 行不等。

1.
Yānīdha bhūtāni samāgatāni, bhummāni vā yāni va antalikkhe;
Sabbeva bhūtā sumanā bhavantu, athopi sakkacca suṇantu bhāsitaṃ.
2.
Tasmā hi bhūtā nisāmetha sabbe, mettaṃ karotha mānusiyā pajāya;
Divā ca ratto ca haranti ye baliṃ, tasmā hi ne rakkhatha appamattā.
3.
Yaṃ kiñci vittaṃ idha vā huraṃ vā, saggesu vā yaṃ ratanaṃ paṇītaṃ;
Na no samaṃ atthi tathāgatena, idampi buddhe ratanaṃ paṇītaṃ;
Etena saccena suvatthi hotu.
4.
Khayaṃ virāgaṃ amataṃ paṇītaṃ, yadajjhagā sakyamunī samāhito;
Na tena dhammena samatthi kiñci, idampi dhamme ratanaṃ paṇītaṃ.

B · 中文译文偈颂（无偈颂号）

译文频道没有 hangnum 句子（偈颂号不译），只有 gatha1/2/last，同样缩进 + 收紧行距 + 大间距分组。

凡会集此诸鬼神，无论地居或空居，
愿一切鬼神欢喜，请恭敬聆听所说。
故一切鬼神倾听：散播慈爱给人类，
日夜持来献供者，故应保护莫放逸。
所有此、他世财富，或于天界殊胜宝，
无有等同如来者。此乃佛之殊胜宝，
以此实语愿安乐！

C · 散文与偈颂混排

散文顶格、行距正常；偈颂缩进、收紧行距。两者混排时，偈颂的缩进让它从散文中凸显出来。

如是我闻：一时，世尊住舍卫城祇树给孤独园。尔时，世尊以是因缘，召集比丘众，而说此偈颂——
凡会集此诸鬼神，无论地居或空居，
愿一切鬼神欢喜，请恭敬聆听所说。
世尊说此偈已，复告诸比丘：此偈乃为护持众生、令得安乐而说。诸比丘闻佛所说，欢喜奉行。
吉祥经已完成。
