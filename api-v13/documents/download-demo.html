一次下载的流程

点击下载→POST /v3/tipitaka-exports→Redis 里有同指纹的包？
有 →200 ready + 下载链接→直接下载
没有 →202 queued，发 RabbitMQ→worker 生成 → 打包 → 写 Redis→前端轮询到 ready→自动下载 / 手动按钮兜底

接口

请求作用
POST /v3/tipitaka-exports
{channel, work?: sn, category?: id, format}		没有 work 和 category = 整个译本。命中缓存 200，否则 202 + Retry-After。同一份包同时只排一次队
GET /v3/tipitaka-exports/{id}轮询状态：queued / running / ready / failed、progress、size、expires_at、download_url
GET /v3/tipitaka-exports/{id}/file?signature=…带签名的链接，浏览器与 App 都能直接下载；Content-Disposition: attachment
